cdr define repl --connect=rep_dus --immed --ats --conflict=ignore --ris --firetrigger --scope=trans --fullrow y rep_auftragextract  \
  'P subvent@rep_dus:tramo.auftragextract' 'select * from auftragextract'  \
  'R subvent@rep_ber:tramo.auftragextract' 'select * from auftragextract'
  


Define source server:
mkdir $INFORMIXDIR/ATS $INFORMIXDIR/RIS
cdr define server --ats=$INFORMIXDIR/ATS --ris=$INFORMIXDIR/RIS  --init  rep_dus

cdr list server
SERVER                 ID STATE    STATUS     QUEUE  CONNECTION CHANGED
-----------------------------------------------------------------------
rep_dus                 1 Active   Local           0

To delete:
cdr delete server rep_dus

Define target server:
mkdir $INFORMIXDIR/ATS $INFORMIXDIR/RIS  
cdr define server --ats=$INFORMIXDIR/ATS --ris=$INFORMIXDIR/RIS  --init  --sync=rep_dus  --connect=rep_ber  rep_ber   --> Can be done in source

Start replication:
cdr start repl rep_auftragextract
cdr list repl

R --> Read Only
